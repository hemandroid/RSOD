# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-03

### Added
- Initial release of RSOD package
- Custom error widget to replace Flutter's Red Screen of Death
- Analytics service interface for error tracking
- Support for both debug and release modes
- Demo page for testing error handling
- Mock analytics service for development
- Comprehensive documentation and examples

### Features
- Easy 3-line integration
- Customizable error screens
- Automatic error logging
- User-friendly error messages
- Debug information in debug mode
- Platform-agnostic analytics interface
